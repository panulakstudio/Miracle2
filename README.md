# Miracle Project – แอป Android (APK)

แอปนี้เป็นตัวห่อ (WebView) ที่เปิดเว็บ https://panulakstudio.netlify.app/ โดยตรง
เนื้อหา ระบบล็อกอิน และข้อมูลทั้งหมดอยู่บนเว็บเดิม แอปแก้เว็บไม่ได้ และเมื่อเว็บอัปเดต แอปจะเห็นการเปลี่ยนแปลงทันที

## 1. ต้องมี
- Android Studio (เวอร์ชันล่าสุด) ดาวน์โหลดจาก developer.android.com/studio
- JDK 17 (Android Studio มีให้ในตัว)

## 2. เปิดโปรเจกต์
1. เปิด Android Studio → File → Open → เลือกโฟลเดอร์ `MiracleApp`
2. รอให้ Gradle sync เสร็จ (ครั้งแรกใช้เวลาหลายนาที และจะดาวน์โหลด Gradle Wrapper ให้เอง)

## 3. ทดสอบบนมือถือ
- เสียบมือถือ เปิดโหมดนักพัฒนา และเปิด USB debugging
- กดปุ่มเล่น ▶ เลือกเครื่อง แล้วแอปจะติดตั้งให้

## 4. สร้างไฟล์ APK สำหรับแจก
- Build → Generate App Bundles or APKs → Generate APKs
- ไฟล์ APK อยู่ที่ `app/build/outputs/apk/`
- ใช้ไฟล์ debug ทดสอบได้เลย แต่ถ้าจะแจกผู้ใช้จริง ให้ทำแบบ Signed:
  Build → Generate Signed App Bundle / APK → สร้าง keystore ใหม่ (เก็บไฟล์และรหัสไว้ให้ดี ถ้าหายจะอัปเดตแอปเดิมไม่ได้)

## 5. เปลี่ยน URL
แก้ค่า `HOME` ในไฟล์ `app/src/main/java/th/miracle/app/MainActivity.kt`

## 6. สิ่งที่แอปทำ
- เปิดเว็บเต็มจอ ปุ่มย้อนกลับของมือถือกลับหน้าก่อนหน้าในเว็บ
- ขอสิทธิ์ตำแหน่ง (GPS) เมื่อเว็บใช้ฟีเจอร์ตำแหน่งเป็นครั้งแรก
- อัปโหลดรูปจากเครื่องได้
- ไฟล์ที่ดาวน์โหลดจากเว็บ (GPX, ICS, CSV, JSON, ไฟล์สำรอง) บันทึกลงโฟลเดอร์ Downloads
- ลิงก์ภายนอก (Google Maps, Instagram, LINE, โทรออก, SMS) เปิดในแอปที่เกี่ยวข้อง
- ไม่มีอินเทอร์เน็ตจะแสดงหน้าแจ้งเตือนพร้อมปุ่มลองใหม่

## 7. ข้อจำกัดที่ต้องรู้
- **บันทึกการขี่ GPS:** ทำงานได้ตอนเปิดแอปอยู่ข้างหน้าเท่านั้น ถ้าสลับไปแอปอื่นหรือล็อกหน้าจอ การบันทึกจะหยุด ต้องใช้ Foreground Service (งานเขียนโค้ดเพิ่ม) ถ้าต้องการให้บันทึกต่อเนื่องจริง
- **เสียงแจ้งเตือน (Speech):** WebView บางรุ่นไม่รองรับเสียงพูดของเว็บ ถ้าเงียบ ให้ใช้เสียงแจ้งเตือนของเครื่องแทน
- **การแจ้งเตือนแบบ Push:** ยังไม่มีในแอปนี้
- **ไอคอนแอป:** ตอนนี้เป็นไอคอนสีฟ้าอย่างง่าย เปลี่ยนได้ที่ `app/src/main/res/drawable/ic_launcher_fg.xml` หรือทำผ่าน Android Studio: File → New → Image Asset

## 8. ก่อนขึ้น Google Play (ถ้าจะเผยแพร่สาธารณะ)
- ต้องมีหน้านโยบายความเป็นส่วนตัว (ข้อมูลตำแหน่งและข้อมูล SOS ต้องอธิบายชัดเจน)
- ต้องอธิบายเหตุผลการขอสิทธิ์ตำแหน่งใน Play Console
- ค่าสมัคร Google Play Developer ครั้งเดียว (25 USD) และต้องยืนยันตัวตนตามที่ Google กำหนด
